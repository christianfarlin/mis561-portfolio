# Data Storytelling with Adobe Express Work Samples

This folder contains my MIS 561 Data Storytelling with Adobe Express work sample and supporting documentation for Farlin Intelligence, my fictional analytics and AI consulting firm.

**Contents:**
- **Executive Work Sample (PDF):** The required Flex 10 deliverable, presenting a one-page, data-driven recommendation for the Chief Financial Officer of Southwest Office Solutions.
- **Farlin Intelligence Brand Identity (Word and PDF):** Optional supporting documentation explaining the thought process behind the firm's name, logo, positioning statement, color palette, typography, accessibility considerations, and human–AI collaboration approach.

**Why two brand identity formats?**

The Word document preserves an editable version of the brand documentation, but GitHub does not provide an inline preview of its contents, so readers generally need to download it to view it. The PDF contains the same information and can be previewed directly in GitHub without downloading anything.

Both formats are included for convenience and accessibility.
